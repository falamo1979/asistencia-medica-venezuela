# Sistema de Asistencia Médica - Venezuela

Sistema web para el registro de consultas médicas, pacientes y tratamientos. Diseñado para emergencias médicas con interfaz responsiva.

## 🚀 Características

- ✅ Registro de consultas médicas
- ✅ Gestión de pacientes y médicos
- ✅ Control de medicamentos suministrados
- ✅ Historial de atenciones por fecha
- ✅ Diseño responsivo (móvil, tablet, desktop)
- ✅ Seguridad con tokens CSRF
- ✅ Base de datos PostgreSQL

## 📋 Requisitos

- PHP 7.4 o superior
- PostgreSQL 12 o superior
- Servidor web (Apache/Nginx)
- Extensión PHP: `php-pgsql`
